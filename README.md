# Tugas 1 - E-Learning Sesi 5

## Website Sederhana Menggunakan HTML, CSS, dan JavaScript

Repository ini dibuat untuk memenuhi tugas pembuatan website sederhana dalam pembelajaran E-Learning Sesi 5.

Pada tugas ini, saya membuat sebuah website satu halaman (single page) menggunakan HTML, CSS, dan JavaScript. Website dirancang dengan tampilan sederhana serta dilengkapi interaksi menggunakan JavaScript.

## Tujuan Pengerjaan

Tujuan dari tugas ini adalah untuk memahami dasar-dasar pengembangan website, meliputi:

- Membuat struktur halaman website menggunakan HTML.
- Mengatur tampilan website menggunakan CSS.
- Menambahkan interaksi sederhana menggunakan JavaScript.
- Memahami cara menyimpan dan mengumpulkan hasil pengerjaan melalui GitHub.

## Teknologi yang Digunakan

- **HTML5** – Membuat struktur dan konten halaman website.
- **CSS3** – Mengatur desain, warna, dan tampilan website.
- **JavaScript** – Menambahkan fungsi interaktif pada halaman website.

## Fitur Website

Website ini memiliki beberapa komponen sesuai dengan ketentuan tugas:

1. **Judul Halaman** – Menampilkan judul atau nama mahasiswa.
2. **Konten Website** – Memiliki minimal satu heading dan tiga paragraf.
3. **Desain CSS** – Menggunakan pengaturan warna background atau warna teks.
4. **Interaksi JavaScript** – Menyediakan tombol yang dapat diklik untuk menjalankan fungsi JavaScript.
5. **Single Page Website** – Seluruh tampilan dibuat dalam satu file HTML.
